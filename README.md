# Computer Vision Lab Task 01

## Description

This repository contains my Computer Vision Lab Task 01. The project demonstrates how to load and display an image using the OpenCV Python library.

## Files

### images.py

The `images.py` Python script uses OpenCV to load an image from the Images folder and display it in a window.

The script uses:

- `cv2.imread()` to load the image.
- `cv2.imshow()` to display the image.
- `cv2.waitKey()` to keep the image window open.
- `cv2.destroyAllWindows()` to close the window.

## Images

The `Images` folder contains two sample images used for testing the OpenCV image-loading program. These are general-purpose images selected for this computer vision lab task.
